# 微排版

## 什么时候使用这个技能

- 用户说「帮我做一个微信图文」「用微排版创建 xxx」时自动触发
- 用户需要基于模板快速生成微信公众号图文作品
- 用户想要 AI 自动完成配色、文本撰写、图片生成等创作流程

## 使用方法

1. 描述你想要的图文主题（如「清明节微信图文」）
2. 从搜索到的模板中选择一个喜欢的
3. AI 自动生成配色方案 → 确认或调整
4. AI 自动生成替换文本 → 确认或调整
5. AI 分析并分类模板中的图片 → 确认分类结果
6. AI 自动生成新图片、去除背景、上传 CDN
7. 所有变更批量提交，返回编辑链接

## 示例

**用户输入：**

> 请帮我用微排版创建一个清明节的微信图文

**技能输出：**

1. 提取标签 `节日`、关键词 `清明`，搜索匹配模板
2. 展示候选模板供用户选择
3. 克隆模板创建作品，分析模板画像（排版类型、色系、密度）
4. 生成清明节主题的清新绿色系配色方案
5. 为每段文本生成清明节主题内容
6. 智能分类图片（场景背景 / 人物 / 装饰 / 文字等），跳过 logo 和二维码
7. 逐张生成新图片并上传
8. 批量更新作品，返回编辑链接：`https://weipaiban.cn/editor/{作品ID}`

## 安全与权限

- 需要 `WEIPAIBAN_API_KEY` 环境变量（`sk-` 开头），在 [微排版 API Keys 页面](https://weipaiban.cn/settings/api-keys) 生成
- 关键步骤（模板选择、配色确认、文本确认、图片分类确认）均需用户明确确认后才继续
- 调用外部 API：微排版平台 API（模板搜索、作品管理、CDN 上传）、即梦 API（图片生成）
